
# VisionAid
An Application For Visually Impaired.



![Logo](images/logo1.png)


## Installation

Build VisionAid from the source and install dependencies:

```bash
# Clone this project
$ git clone https://github.com/bappa-arc/visionaid_ar.git

# Access
$ cd visionaid_ar

# Install dependencies
$ flutter pub get

# Run
$ flutter run
```
